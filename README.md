# Skills da Imersão CEOs

Skills de agente usadas na Imersão CEOs da Adapta.

<table>
<tr><th>Skill</th><th>O que faz</th></tr>
<tr><td><code>imersao-ceos-entender</code></td><td>Transforma relatórios e dados reais nas perguntas que o CEO deveria fazer, no que está estranho e no que acontece se nada mudar.</td></tr>
<tr><td><code>imersao-ceos-decidir</code></td><td>Prepara uma decisão real: dimensiona o impacto, define critérios, gera alternativas e entrega uma recomendação com premissas explícitas.</td></tr>
<tr><td><code>imersao-ceos-comunicar</code></td><td>Escreve a comunicação do CEO começando pelo receptor e no tom do próprio usuário.</td></tr>
<tr><td><code>imersao-ceos-guardanapo-para-sistema</code></td><td>Transforma a dinâmica do Guardanapo no menor sistema funcional que resolve um caso real, construído pelo MCP do Skip.</td></tr>
</table>

## Instalação

```bash
npx skills add adapta-school/imersao-ceos-skills
```

Cada skill fica em `skills/<nome>/SKILL.md`.
